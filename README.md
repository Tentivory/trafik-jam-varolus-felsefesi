# Trafik Jam Varoluş Felsefesi Makinesi

## Bu Nedir?

Bu proje, Türkiye'nin efsanevi trafik sıkışıklıklarında geçirdiğiniz o sonsuz dakikaları, derin varoluşsal sorgulara dönüştüren **en gelişmiş** (ve en gereksiz) yazılımıdır.

Trafikte beklerken sadece kornaya basmak yerine, evrenin anlamını, hayatın amacını ve "Neden bu kadar yavaş gidiyoruz?" sorusunun kozmik boyutunu keşfedin.

## Özellikler

- Gerçek zamanlı trafik bekleme simülasyonu (aslında sadece sleep)
- Rastgele absürt felsefi cümleler üretir
- Her çalıştırmada hayatınızı sorgulatır
- Hiçbir şeyi çözmez, sadece düşündürür
- %100 Türkçe, %200 saçma

## Kurulum

```bash
git clone https://github.com/Tentivory/trafik-jam-varolus-felsefesi.git
cd trafik-jam-varolus-felsefesi
python trafik_felsefe.py
```

## Uyarı

Bu yazılımı kullanmak, trafik sıkışıklığını azaltmaz. Aksine, siz felsefe yaparken arka araçlar daha çok korna çalar.
